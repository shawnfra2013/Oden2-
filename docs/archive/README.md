# Historical Odin documentation (not operating instructions)

All documents in this directory are **immutable snapshots of earlier plans, tests, milestones, and hosting decisions** as they existed before the November 22, 2026 cleanup. They are retained for provenance and troubleshooting, not as current architecture. Some relative links and command examples reflect their original location and may no longer be valid.

The source of truth for the actual supported stack is [CURRENT runtime](../ODIN_RUNTIME.md). For active work use [issues](../TASK_BOARD.md), [release gates](../RELEASE_GATES.md), [decisions](../DECISIONS.md), and [handoff](../HANDOFF.md). Do not infer a current source SHA, available phone host, or live device from these snapshots.
